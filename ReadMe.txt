## 📌 Overview

This project is an advanced 3D game developed using OpenGL and C++ as part of a Computer Graphics final project. It demonstrates a complete real-time interactive environment with multiple levels, camera systems, lighting, and physics-like interactions.

---

## 🎮 Gameplay

* Explore multiple 3D environments (different levels)
* Control a player using keyboard and mouse
* Switch between first-person and third-person camera views
* Avoid obstacles and interact with objects
* Collect items and reach objectives to increase score
* Complete the game within constraints to win

---

## 🚀 Features

* Multi-level 3D environments
* First-person and third-person camera systems
* Real-time player movement and rotation
* Collision detection with objects and boundaries
* Fully textured 3D models
* Dynamic lighting with color and intensity variations
* Light animations and transformations
* Interactive animations triggered by user actions
* Score system displayed during gameplay
* Keyboard and mouse interaction

---

## 🧠 Concepts Demonstrated

* 3D rendering and transformation pipeline
* Camera systems and perspective control
* Lighting models and light animation
* Texture mapping
* Collision detection
* Scene management and game logic
* Real-time event handling
